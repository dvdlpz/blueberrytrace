# Experiencia de usuario operativa

BlueberryTrace presenta sus acciones y mensajes para el personal operativo y administrativo de Vivero Los Viñedos.

## Principios aplicados

- Los formularios indican el propósito de cada registro y agrupan la información por etapas.
- Los requisitos previos explican qué debe registrarse antes de continuar, sin referirse a componentes internos.
- Los mensajes de error utilizan nombres de campos comprensibles, como **Invernadero**, **Lote trazable** o **Clasificación validada**.
- Los estados vacíos muestran la siguiente acción útil: crear el primer invernadero, registrar una cama o iniciar una siembra.
- Los modales conservan un encabezado, una descripción breve y acciones claras para guardar o cancelar.
- El panel principal muestra una guía de avance operativo para orientar el siguiente registro disponible.

## Guía de avance operativo

El panel principal propone el siguiente paso según los registros disponibles:

1. Registrar invernaderos.
2. Registrar camas.
3. Crear un lote trazable.
4. Registrar una siembra.
5. Registrar uniformización.
6. Registrar formalización.
7. Registrar clasificación.
8. Registrar despacho.

La guía no reemplaza los controles de autorización. Cada usuario solo puede abrir los módulos permitidos para su perfil.
