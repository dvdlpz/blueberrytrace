# Interfaz corporativa y permisos

## Navegación fija

En pantallas de escritorio, la navegación principal permanece visible mientras se revisan registros extensos. En pantallas pequeñas conserva un comportamiento móvil desplegable para no reducir el área de trabajo.

## Formularios y modales

Los formularios se organizan por secciones, con una jerarquía visual uniforme y acciones fijas al final de cada ventana. Los mensajes explican qué debe hacer la persona usuaria y evitan términos técnicos del sistema.

## Roles y permisos

Los cinco perfiles institucionales se conservan como códigos fijos. Administración puede personalizar:

- descripción visible;
- color de identificación;
- acciones autorizadas por área mediante selección individual.

La aplicación conserva los accesos esenciales del perfil administrativo para evitar que el sistema quede sin gestión autorizada. Los cambios de permisos invalidan las sesiones de las personas asignadas para que la nueva configuración se aplique al siguiente acceso.

## Reportes y auditoría

La vista previa de reportes desplaza la página de forma vertical sin moverla horizontalmente. Las tablas extensas se desplazan dentro de su contenedor. Auditoría incorpora filtros por texto, área y período con controles visuales consistentes.
